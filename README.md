# Service Launch Studio

The first product in MicroSAAS. This MVP helps an aspiring freelancer choose a service, write an offer, preview a storefront, and download that storefront as a standalone HTML file. Drafts are saved in the browser with localStorage. Downloading the file does not publish it.

There are no accounts, payments, databases, or AI calls in this version.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run typecheck
npm run lint
npm test
npm run build
```
