# Service Launch Studio

The first product in MicroSAAS. This MVP helps an aspiring freelancer choose a service, write an offer, and preview a storefront. Drafts are saved in the browser with localStorage.

There are no accounts, payments, databases, or AI calls in this version.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run typecheck
npm run lint
npm run build
```
